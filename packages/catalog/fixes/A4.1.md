## Summary

If the store runs an MCP server, publish a server card at /.well-known/mcp/server-card.json with a name and endpoint.

## Snippet

```json
{
  "name": "Example Shop",
  "description": "Catalog search and order status for Example Shop",
  "endpoint": "https://example.shop/mcp",
  "transport": "streamable-http"
}
```

## Agent prompt

Publish /.well-known/mcp/server-card.json on this site describing its MCP server (name, description, endpoint URL, transport). Serve it as application/json with a short cache lifetime.
