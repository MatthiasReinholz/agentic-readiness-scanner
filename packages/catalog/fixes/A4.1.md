## Summary

If the site runs an MCP server, publish a server card at <endpoint>/server-card and list it in /.well-known/ai-catalog.json, the two routes the MCP Server Card extension describes. Link the endpoint from llms.txt as well.

## Snippet

```json
{
  "identifier": "urn:air:example.com:shop",
  "type": "application/mcp-server-card+json",
  "url": "https://example.com/mcp/server-card"
}
```

## Agent prompt

If this site operates an MCP server, publish a server card (name, version, description, remote transport endpoints) at <endpoint>/server-card served as application/mcp-server-card+json with Access-Control-Allow-Origin: * and a public cache lifetime, add an entry of type application/mcp-server-card+json to /.well-known/ai-catalog.json, and link the endpoint from llms.txt. Do not publish a card for a server that does not exist.
