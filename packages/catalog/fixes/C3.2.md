## Summary

If you sell online to consumers in Argentina, put a link labelled "Botón de arrepentimiento" on the first screen of the home page, and a "Botón de baja" link as well when you sell services or subscriptions, each leading to a form that needs no registration. Have a lawyer review the flow.

## Snippet

```html
<header>
  <nav aria-label="Atención al consumidor">
    <a href="/arrepentimiento">Botón de arrepentimiento</a>
    <a href="/baja">Botón de baja de servicios</a>
  </nav>
</header>
```

## Agent prompt

Add Argentina's botón de arrepentimiento to this store, as required by Disposición SSDCyLC 954/2025. Place a link or button with the visible text "Botón de arrepentimiento" in a prominent position on the first screen of the home page (header or top bar, visible without scrolling), in the server-rendered HTML. If the store sells services or subscriptions, add a second link "Botón de baja de servicios" next to it. Each link leads to a short form that does not require an account or login: name, contact email, order or contract number, and a submit button. On submission, show and email the consumer a request code, and route the request to the order team. On WordPress/WooCommerce, use a header menu item and the site's form plugin; on Shopify, use the theme's header or announcement bar and a page with a form app. Check the result on a mobile viewport, where the first screen is smallest. Do not write the legal text on the form page; leave a note that a lawyer must review the flow and texts.
