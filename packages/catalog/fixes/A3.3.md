## Summary

Keep product HTML under 1 MB and the response under 3 seconds with page caching, deferred scripts and trimmed inline assets. Googlebot reads only the first 2 MB of a page.

## Agent prompt

A scan found product pages (or the home page) with 1 MB or more of HTML, a response time of 3 seconds or more, or HTML past the 2 MB that Googlebot reads. Find what makes the HTML heavy: inline JSON state, inline SVG sprites, base64 images, duplicated structured data blocks and variant data rendered as hidden markup are the usual causes. Enable full-page caching for anonymous visitors, move large inline scripts, styles and JSON into cached external files, keep one structured data block and place it early in the page. Target under 1 MB of uncompressed HTML and under 3 seconds to a complete response. Verify with `curl -s -H 'Accept-Encoding: identity' <product URL> | wc -c` and `curl -s -o /dev/null -w '%{time_total}' <product URL>`.

## On WordPress

Turn on full-page caching for visitors who are not logged in, and use the page builder's option to load CSS and JavaScript as external files.
