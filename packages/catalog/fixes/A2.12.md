## Agent prompt

This Salesforce B2C Commerce storefront serves a robots.txt that shuts search crawlers out of the whole site or out of /on/demandware.static/, where the storefront's scripts, styles and images live. In Business Manager, open the App Launcher, go to Merchant Tools > (site) > SEO > Robots, choose "Define robots.txt Specific to Instance Type" and select the production instance. Set it to "All Spiders Allowed to Access Any Static Resources", or write a custom robots.txt that disallows only cart, checkout, account and search-result URLs and keeps product pages and /on/demandware.static/ open. Keep "All Spiders Disallowed to Access Any Static Resources" for development and staging only. robots.txt is a site preference: if production gets it by replicating site preferences from staging, set the instance-specific production value before the next replication, or the staging rules come back. If a cartridge ships its own robots.txt, change it there and replicate the code. Verify that https://<domain>/robots.txt no longer contains Disallow: / for all agents or a Disallow rule for /on/demandware.static/.
