## Summary

Fix GTINs that fail the GS1 check digit. A mistyped or transposed digit, or a number copied from the wrong product, is the usual cause; padding with leading zeros does not change the check digit.

## Agent prompt

Validate every GTIN on this store against the GS1 check-digit algorithm. For each one that fails, look up the correct number in the supplier's or manufacturer's data or the GS1 registry and replace it, correcting mistyped and transposed digits; adding or removing leading zeros does not fix a wrong check digit. Reject new values on save when they fail validation.
