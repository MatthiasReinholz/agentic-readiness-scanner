## Summary

Publish an XML sitemap and declare it in robots.txt, so crawlers and agents can enumerate the site without following links.

## Snippet

```robots
Sitemap: https://example.com/sitemap.xml
```

## Agent prompt

Ensure this site serves a sitemap index at a stable URL that returns HTTP 200 with valid sitemap XML, and add a Sitemap: line for it to robots.txt.

## On WordPress

Core WordPress serves /wp-sitemap.xml; SEO plugins usually replace it with /sitemap_index.xml. If an SEO plugin provides the sitemap, point the Sitemap line at that plugin's index instead of the core one.

## On Shopify

Shopify generates /sitemap.xml and declares it in robots.txt; when this check fails, look for a robots.txt.liquid template or a proxy that removed the line.
