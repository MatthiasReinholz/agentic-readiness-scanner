## Summary

Publish an XML sitemap and declare it in robots.txt, so crawlers and agents can list the site's pages without following links.

## Snippet

```robots
Sitemap: https://example.com/sitemap.xml
```

## Agent prompt

The scanner found no usable sitemap on this site: none of the Sitemap lines in robots.txt, /sitemap.xml, /sitemap_index.xml or /wp-sitemap.xml answered HTTP 200 with valid sitemap XML on the store's own host, or the sitemap it found lists no URLs. Make the site serve a sitemap index (or a single URL set) at a stable URL on the same host as the pages, generated from the platform or catalog data so it lists every published page and product. Serve it as uncompressed XML with absolute URLs. Add a `Sitemap:` line with its absolute URL to robots.txt. Verify with `curl -sS -D - https://<domain>/sitemap.xml` (or the declared URL): status 200 and a body that starts with `<urlset` or `<sitemapindex` and lists at least one entry.

## On WordPress

Core WordPress serves /wp-sitemap.xml, and SEO plugins usually replace it with /sitemap_index.xml. If an SEO plugin provides the sitemap, point the Sitemap line at that plugin's index instead of the core one.

## On Shopify

Shopify generates /sitemap.xml and declares it in robots.txt. When this check fails, look for a robots.txt.liquid template or a proxy that removed the line.
