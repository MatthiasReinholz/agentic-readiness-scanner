## Summary

Publish an XML sitemap and declare it in robots.txt. WordPress ships one at /wp-sitemap.xml; SEO plugins usually replace it with /sitemap_index.xml.

## Snippet

```robots
Sitemap: https://example.com/wp-sitemap.xml
```

## Agent prompt

Ensure this site serves a sitemap index at a stable URL that returns HTTP 200 with valid sitemap XML, and add a Sitemap: line for it to robots.txt. If an SEO plugin provides the sitemap, point the line at that plugin's index instead of the core one.
