## Summary

Expose variable products as a ProductGroup whose hasVariant lists each variation with its own sku, identifiers and offer.

## Snippet

```json
{
  "@context": "https://schema.org",
  "@type": "ProductGroup",
  "name": "Stoneware Mug",
  "productGroupID": "MUG-350",
  "variesBy": ["https://schema.org/color"],
  "hasVariant": [
    {
      "@type": "Product",
      "sku": "MUG-350-BLU",
      "color": "Blue",
      "offers": {
        "@type": "Offer",
        "price": "24.00",
        "priceCurrency": "EUR",
        "availability": "https://schema.org/InStock"
      }
    }
  ]
}
```

## Agent prompt

For products with variants on this site, output a schema.org ProductGroup with productGroupID, variesBy and a hasVariant array that contains one Product per variant, each with sku, gtin where available, the varying attribute values and its own Offer. Generate it from the catalog data so new variants appear without manual edits. On WordPress/WooCommerce: filter the JSON-LD WooCommerce emits (woocommerce_structured_data_product) and build hasVariant from the variable product's variations.
