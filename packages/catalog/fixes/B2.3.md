## Summary

Expose variable products as a ProductGroup whose hasVariant lists each variation with its own sku, identifiers and offer.

## Snippet

```json
{
  "@context": "https://schema.org",
  "@type": "ProductGroup",
  "name": "Stoneware Mug",
  "productGroupID": "MUG-350",
  "variesBy": ["https://schema.org/color"],
  "hasVariant": [
    {
      "@type": "Product",
      "sku": "MUG-350-BLU",
      "color": "Blue",
      "offers": {
        "@type": "Offer",
        "price": "24.00",
        "priceCurrency": "EUR",
        "availability": "https://schema.org/InStock"
      }
    }
  ]
}
```

## Agent prompt

For variable products on this WooCommerce site, output a schema.org ProductGroup with productGroupID, variesBy and a hasVariant array that contains one Product per variation, each with sku, gtin where available, the varying attribute values and its own Offer.
