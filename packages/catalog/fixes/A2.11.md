## Summary

## Agent prompt

This Square Online site is hidden from search engines. In the Square Dashboard, go to Online > Website > SEO. Under Search Engine Optimization (SEO), clear "Hidden from search engine results" for the site, then publish. Also check the most important pages (home, shop, product pages): open Online > Website > Edit site, select the page, open the gear icon, View page settings > SEO, and make sure Search visibility is not set to hidden. Publish again. Confirm afterwards that the home page HTML has no robots meta tag with noindex and that /robots.txt does not disallow all crawlers.
