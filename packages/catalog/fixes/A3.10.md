## Summary

Declare a responsive viewport on every page and let the layout adapt, so the smartphone crawler Google indexes with sees a usable page.

## Snippet

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

## Agent prompt

Add <meta name="viewport" content="width=device-width, initial-scale=1"> to the head of every page template of this store (theme header or layout file), remove any fixed pixel width in the viewport tag, and do not disable zooming (no user-scalable=no, no maximum-scale below 1). Then check on a narrow viewport that the main product content, price and add-to-cart control are visible without horizontal scrolling and match the desktop page. Verify by fetching a product page and confirming the viewport tag is in the server-rendered HTML.
