## Summary

If you publish llms.txt, make it a plain-text Markdown file that starts with an H1 naming the site, followed by a short blockquote summary and link lists. If you do not publish one, nothing is lost: no major assistant documents reading it.

## Snippet

```markdown
# Example Shop

> Independent retailer of hand-made ceramics, shipping to the EU and UK.

## Catalog

- [Product feed](https://example.com/feed/products.xml): Google-format XML, refreshed hourly
- [Product sitemap](https://example.com/product-sitemap.xml)

## Policies

- [Shipping](https://example.com/shipping/)
- [Returns](https://example.com/returns/)
```

## Agent prompt

Fix /llms.txt on this site so it is served as text (text/markdown or text/plain, never an HTML page), begins with a level-one heading that names the site, has a one-paragraph blockquote summary, and lists links in H2 sections (for a store: products, policies, APIs). Keep it short; agents that read it are pointed at it explicitly. On WordPress/WooCommerce, prefer the platform's own hooks and settings over editing theme files, and verify the change on a product page and on the home page afterwards.
