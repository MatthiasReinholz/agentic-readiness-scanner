## Summary

Model the brand as a Brand object with a canonical name, sourced from one brand taxonomy rather than free text.

## Snippet

```json
"brand": { "@type": "Brand", "name": "Example Ceramics" }
```

## Agent prompt

Give this store one canonical source of brand names (a brand taxonomy or a vendor field, not free text), assign every product exactly one brand from it, and output it in the Product JSON-LD as a Brand object with that name. Normalize casing so the same brand never appears twice. On WordPress/WooCommerce: use the built-in product brands taxonomy, assign one term per product and map it into the structured data.
