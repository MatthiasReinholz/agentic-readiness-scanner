## Summary

Answer requests for URLs that do not exist with HTTP 404 (or 410), not with a 200 page or a redirect to the home page, so agents can tell a missing page from content.

## Agent prompt

Make this site return HTTP 404 (or 410 for removed pages) for unknown URLs. Find the handler, front controller, CDN or hosting rule that currently answers 200 with an HTML page or redirects to the home page, and correct it; keep the friendly not-found page but with the 404 status. Verify with curl -I on a random path. On WordPress/WooCommerce, prefer the platform's own hooks and settings over editing theme files, and verify the change on a product page and on the home page afterwards.
