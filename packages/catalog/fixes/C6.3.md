## Summary

When a product image was made or edited with an AI tool, keep the generation metadata the tool embedded (a C2PA manifest, or the IPTC DigitalSourceType value trainedAlgorithmicMedia) through your upload, optimisation and CDN pipeline, or add the IPTC value yourself. Where the metadata cannot survive, say in the visible product content that the image is AI-generated, and have the wording reviewed by someone qualified.

## Snippet

```bash
# Mark an AI-generated image with the IPTC digital source type (XMP)
exiftool -XMP-iptcExt:DigitalSourceType="http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia" product-hero.jpg

# Check what an image carries, including a C2PA manifest
exiftool -XMP-iptcExt:DigitalSourceType -JUMBF:All product-hero.jpg
```
