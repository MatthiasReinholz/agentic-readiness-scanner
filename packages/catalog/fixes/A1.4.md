## Summary

Emit Link response headers on the front page and product pages that point agents at the machine-readable resources the site has: llms.txt, a Markdown alternate, an API catalog, an RSL licence or the UCP profile.

## Snippet

```http
Link: </llms.txt>; rel="llms-txt"; type="text/markdown", </.well-known/api-catalog>; rel="api-catalog"
```

## Agent prompt

Add Link response headers (RFC 8288) to the home page and product pages for every agent-facing resource this site already serves, for example `</llms.txt>; rel="llms-txt"; type="text/markdown"`, `</.well-known/api-catalog>; rel="api-catalog"` or `</.well-known/ucp>; rel="ucp"`. Do not advertise resources that do not exist. On WordPress/WooCommerce, prefer the platform's own hooks and settings over editing theme files, and verify the change on a product page and on the home page afterwards.
