## Summary

Publish a UCP business profile at /.well-known/ucp that declares the services, capabilities and payment handlers the store actually has, served as JSON over HTTPS without redirects and with Cache-Control: public, max-age of at least 60.

## Snippet

```json
{
  "ucp": {
    "version": "2026-08-25",
    "services": {},
    "capabilities": {},
    "payment_handlers": {}
  }
}
```

## Agent prompt

Publish /.well-known/ucp on this site as application/json, directly (no redirect), with Cache-Control: public, max-age=60 or longer: a ucp object with version (the specification date you implement, YYYY-MM-DD), a services object (dev.ucp.shopping with transport rest, mcp or a2a and its endpoint when you have one), a capabilities object and a payment_handlers object. Declare only what is implemented; both maps may be empty. On Shopify this profile is served by the platform for eligible stores and should not be hand-written.
