## Summary

Emit Organization JSON-LD with legal name, address and contact point, and publish an imprint or about page with the same details.

## Snippet

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Example Ceramics GmbH",
  "url": "https://example.shop/",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Musterstraße 1",
    "postalCode": "10115",
    "addressLocality": "Berlin",
    "addressCountry": "DE"
  },
  "contactPoint": {
    "@type": "ContactPoint",
    "email": "hello@example.shop",
    "contactType": "customer service"
  }
}
```

## Agent prompt

Add Organization JSON-LD to the homepage of this site with the legal name, postal address and a contact point, and make sure an imprint or about page states the same information in text.
