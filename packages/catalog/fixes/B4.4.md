## Summary

Add Organization JSON-LD with your legal name, postal address and a contact point to the home page, and state the same details on an imprint (legal notice) page if you publish one.

## Snippet

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Example Ceramics GmbH",
  "url": "https://example.com/",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Musterstraße 1",
    "postalCode": "10115",
    "addressLocality": "Berlin",
    "addressCountry": "DE"
  },
  "contactPoint": {
    "@type": "ContactPoint",
    "email": "hello@example.com",
    "contactType": "customer service"
  }
}
```

## Agent prompt

The scanner found no complete merchant identity on this site: no Organization JSON-LD with a name plus an address, contactPoint, telephone or email on the home page, imprint page or contact page, and no imprint page whose text shows a postal address. Add Organization JSON-LD (or a subtype such as OnlineStore) to the home page with the legal name, url, a PostalAddress and a ContactPoint with an email or phone number. If the site has an imprint or legal notice page, state the same name and address there as text and link it from the footer with a label such as "Imprint" or "Legal notice". Verify the home page source contains the Organization node and test it in the Schema Markup Validator at validator.schema.org.
