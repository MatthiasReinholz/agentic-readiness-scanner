## Summary

Generate the Product markup from the same product object that renders the page so price and availability can never diverge, and avoid caching markup separately from the page.

## Agent prompt

Find why the JSON-LD price or availability on product pages of this site differs from the rendered values. Common causes are an SEO plugin caching markup, tax-inclusive versus tax-exclusive display settings, or a stale object cache. Make both come from one source.
