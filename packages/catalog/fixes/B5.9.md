## Summary

Switch on Storefront MCP under Settings > API and MCP > MCP in the BigCommerce control panel so the WebMCP bridge in your storefront has a server behind it; guests can then search, fill a cart and hand off to checkout through an agent.

## Agent prompt

This BigCommerce storefront either advertises a WebMCP bridge whose Storefront MCP server does not answer, or advertises no MCP server at all. As the store owner, open the BigCommerce control panel, go to Settings > API and MCP > MCP, switch on Storefront MCP for this storefront and accept the terms; the server can take up to ten minutes to become available. Keep the WebMCP bridge enabled (it is on by default for eligible Stencil and Catalyst storefronts) unless there is a reason to opt out. Make sure robots.txt and any WAF rule allow POST requests to the MCP path the bridge names. Verify that the home page contains a script from /.webmcp/bridge.js with a data-mcp-url attribute and that a JSON-RPC request to that URL returns a JSON-RPC message.
