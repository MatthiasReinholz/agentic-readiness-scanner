## Summary

Turn on Friendly URL under Shop Parameters > Traffic & SEO > SEO & URLs once you have confirmed the server supports URL rewriting, then regenerate robots.txt; product URLs become readable paths such as /12-blue-mug.html.

## Agent prompt

This PrestaShop store serves product URLs as query strings (index.php?id_product=…), which means Friendly URL is off. First confirm that the web server supports URL rewriting (Apache with mod_rewrite and AllowOverride for .htaccess, or the PrestaShop rules for nginx). In the back office open Shop Parameters > Traffic & SEO, set Friendly URL to Yes in the SEO & URLs settings and save; PrestaShop rewrites .htaccess. Open a product, a category and the cart in a private window to confirm the shop still works; if pages answer 404, switch the option back and fix the server configuration first. Then click "Generate robots.txt" on the same page (it replaces the file, so keep a copy of custom rules and add them back), and resubmit the sitemap. Make sure old query-string URLs redirect or carry a canonical link to the friendly URL.
