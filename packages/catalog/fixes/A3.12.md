## Summary

Turn on Friendly URL under Shop Parameters > Traffic & SEO > SEO & URLs once you have confirmed the server supports URL rewriting. Product URLs then become readable paths such as `/12-blue-mug.html`.

## Agent prompt

This PrestaShop store serves product URLs as query strings (`index.php?id_product=…`), which means Friendly URL is off. First confirm that the web server supports URL rewriting (Apache with mod_rewrite and AllowOverride for .htaccess, or the PrestaShop rules for nginx). In the back office open Shop Parameters > Traffic & SEO, set Friendly URL to Yes in the SEO & URLs settings and save. PrestaShop then rewrites .htaccess. Open a product, a category and the cart in a private window to confirm the shop still works. If pages answer 404, switch the option back and fix the server configuration first. If you click "Generate robots.txt" on the same page, keep a copy of custom rules first, because it replaces the file. Resubmit the sitemap, and make sure old query-string URLs redirect or carry a canonical link to the friendly URL. Verify that the product links in the home page and the sitemap no longer contain `id_product=`.
