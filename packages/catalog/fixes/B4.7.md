## Summary

Informational. Serve /.well-known/security.txt with a Contact and an Expires field if you want a disclosure channel; it is not an agent-readiness signal.

## Snippet

```text
Contact: mailto:security@example.com
Expires: 2027-06-01T00:00:00Z
Preferred-Languages: en, de
```

## Agent prompt

Only if the owner wants one: serve /.well-known/security.txt as text/plain with a Contact: field (email or URL) and an Expires: field (RFC 3339, within a year), as RFC 9116 describes.
