## Summary

Keep the Shopify storefront's /products.json readable: remove the storefront password once the store is live, and find the app, proxy or robots.txt rule that blocks the endpoint.

## Agent prompt

On this Shopify store, https://<shop>/products.json does not answer anonymous requests with a JSON object that holds a products array. Instead it answered with an error status, the storefront password page, an HTML page or a non-JSON body, or robots.txt disallows it. Check, in order: the storefront password under Online Store, Preferences (turn it off if the store is live), apps that redirect, localise or protect the storefront and may intercept the route, firewall or bot rules on a proxy or CDN in front of Shopify, and a Disallow for /products.json in robots.txt.liquid. Products appear only when they are published to the Online Store sales channel. Verify with `curl -s 'https://<shop>/products.json?limit=5' | jq '.products | length'`, which must print a number. HTTP 429 means Shopify's per-IP rate limit, so wait a minute and retry.
