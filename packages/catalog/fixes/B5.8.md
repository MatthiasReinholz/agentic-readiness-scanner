## Summary

Agentic storefronts is active by default for eligible Shopify stores, so a missing UCP profile or MCP endpoint means the store is ineligible (password page, a plan without the channel, a storefront not served by Shopify) or the channel was turned off; fix the cause rather than a setting, and keep /api/ucp/mcp reachable for agents.

## Agent prompt

In the Shopify admin of this store, open Sales channels and confirm Agentic storefronts is present and active (it is on by default for eligible stores). If it is absent, check eligibility: remove the storefront password once the store is live, confirm the plan includes the channel and that the storefront is served by Shopify (a headless storefront on another host does not get the profile or the endpoint on its own domain). Then verify that responses carry Link: </.well-known/ucp>; rel="ucp", that /.well-known/ucp answers JSON, and that /api/ucp/mcp answers a JSON-RPC request. If robots.txt disallows /api/ for all agents, consider an Allow rule for /api/ucp/ so agents that honour robots.txt can reach the catalog.
