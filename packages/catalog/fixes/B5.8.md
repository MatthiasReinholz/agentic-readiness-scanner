## Summary

Agentic storefronts is active by default for eligible Shopify stores. A missing UCP Link header or MCP endpoint means the store is ineligible (password page, a plan without the channel, a storefront not served by Shopify) or the channel was turned off, so fix the cause and keep `/api/ucp/mcp` reachable for agents.

## Agent prompt

In the Shopify admin, open Sales channels and confirm Agentic storefronts is present and active (it is on by default for eligible stores). If it is absent, check eligibility: remove the storefront password once the store is live, confirm the plan includes the channel and that the storefront is served by Shopify (a headless storefront on another host does not get the profile or the endpoint on its own domain). If robots.txt disallows `/api/` for all agents, consider an Allow rule for `/api/ucp/`. Verify with `curl -sI` that the home page carries the Link header, that `/.well-known/ucp` answers JSON, and that a JSON-RPC POST to `/api/ucp/mcp` returns a JSON-RPC message.
