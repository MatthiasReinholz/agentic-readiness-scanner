## Summary

Make the WooCommerce Store API readable without credentials. It is public by default, so a security plugin, a REST API restriction or a firewall rule is usually what blocks it.

## Agent prompt

On this WooCommerce site, the public Store API at /wp-json/wc/store/v1/products does not answer anonymous requests with a JSON list of products. It is public by default, so find the layer that blocks it: REST API restriction plugins, security plugins that disable the REST API for logged-out users, a plain permalink structure (Settings, Permalinks), custom rest_authentication_errors or rest_endpoints filters, and WAF, CDN or host rules on /wp-json/. Allow anonymous GET requests to /wp-json/wc/store/ and keep the authenticated /wp-json/wc/v3 REST API protected. Verify with `curl -s -i 'https://<domain>/wp-json/wc/store/v1/products?per_page=1'` from outside your network: it must answer HTTP 200 with content-type application/json and a body that starts with `[`.
