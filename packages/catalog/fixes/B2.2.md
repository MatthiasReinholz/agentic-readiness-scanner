## Summary

Add an Offer to the Product markup with price, priceCurrency and an availability URL from schema.org/ItemAvailability.

## Snippet

```json
"offers": {
  "@type": "Offer",
  "price": "24.00",
  "priceCurrency": "EUR",
  "availability": "https://schema.org/InStock",
  "priceValidUntil": "2027-12-31"
}
```

## Agent prompt

Extend the Product JSON-LD on this site so offers carry price as a decimal string, priceCurrency as an ISO 4217 code, and availability as a full schema.org URL (InStock, OutOfStock, PreOrder, BackOrder) derived from live stock status.
