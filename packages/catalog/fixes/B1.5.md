## Summary

If you want any agent to read the whole catalog as data, publish a product feed in the Google or OpenAI format at a stable public URL and link it with a rel=alternate tag and from llms.txt. No shopping channel requires a public copy, because they ingest the feeds you push to them.

## Snippet

```html
<link
  rel="alternate"
  type="application/rss+xml"
  title="Product feed"
  href="https://example.com/feed/products.xml"
/>
```

## Agent prompt

No public product feed was found for this site: none was linked from the home page, llms.txt, robots.txt or the sitemap, or the linked file is not a product feed. Publish one at a stable public URL whose path names it, such as /feed/products.xml, in Google Merchant Center XML (RSS with the g: namespace `http://base.google.com/ns/1.0`) or the OpenAI feed format (CSV, TSV, JSON or JSON Lines with item_id, title, url and price columns). Give each item id, title, description, link, image_link, price, availability, brand and gtin or mpn, and regenerate it at least daily from the same data that renders product pages. Start from the feed already sent to a shopping channel if there is one, and never put a secret token in the URL. Link it from the home page head with `<link rel="alternate" type="application/rss+xml" title="Product feed" href="...">` and from llms.txt. Verify with `curl -s <feed-url> | head -c 1500` (the XML must declare xmlns:g, a CSV header must name id, title, link and price) and check that the home page source contains the link tag.
