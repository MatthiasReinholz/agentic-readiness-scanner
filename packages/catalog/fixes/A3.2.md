## Summary

Render product title, price and description into the HTML on the server. An app shell that fills in content with JavaScript is empty to most agents.

## Agent prompt

A scan found sampled product pages whose raw HTML lacks the product title, price or description, or product URLs that land on a sign-in or password page. Make product pages server-render the title, the price with currency, the availability and the description into the initial HTML response. If the storefront is a JavaScript application, add server-side rendering or static prerendering for product routes. Embed Product JSON-LD in the server response, not through a tag manager. Remove any coming-soon, maintenance, members-only or storefront password mode that sends product URLs to a login page. Verify with `curl -sL <product URL>` that the product name and price appear in the output without running JavaScript.
