## Summary

Add a Catalog section to llms.txt that links to the product feed, the product API or the product sitemap, so an agent that reads the file reaches the catalog as data in one hop.

## Snippet

```markdown
## Catalog

- [Product feed](https://example.com/feeds/products.xml): Google Merchant Center XML
- [Product sitemap](https://example.com/sitemap-products.xml)
```

## Agent prompt

This site's /llms.txt is valid but none of its links leads to the catalog as data: no link to a product feed, a product API, a product sitemap, the shop or products index, a UCP profile or an MCP endpoint. Edit /llms.txt and add an H2 section named Catalog with Markdown links (link text in square brackets, followed by the URL in round brackets) to the public product feed if there is one, the product API the platform offers and the product sitemap, each with a short note on what it returns. Keep the existing sections. Link only public URLs that answer without a login. Verify by fetching /llms.txt and opening each catalog link with `curl -sI`: each must answer HTTP 200.

## On WordPress

Edit the static llms.txt in the web root, or the plugin that generates it, rather than theme files.

## On WooCommerce

Link the Store API at /wp-json/wc/store/v1/products as the product API.

## On Shopify

Link /products.json as the product API, and the UCP profile at /.well-known/ucp when Agentic storefronts is active.
