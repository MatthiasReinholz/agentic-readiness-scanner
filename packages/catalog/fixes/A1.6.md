## Summary

Add a Catalog section to llms.txt that links to the product feed, the product API or the product sitemap, so an agent that reads the file reaches the catalog as data in one hop.

## Snippet

```markdown
## Catalog

- [Product API](https://example.com/wp-json/wc/store/v1/products): JSON, live price and stock
- [Product sitemap](https://example.com/wp-sitemap-posts-product-1.xml)
```

## Agent prompt

Edit /llms.txt on this site and add an H2 section named Catalog with links to the catalog as data: the public product feed if there is one, the product API (for WooCommerce /wp-json/wc/store/v1/products, for Shopify /products.json) and the product sitemap. Keep the existing sections. On WordPress/WooCommerce, prefer the platform's own hooks and settings over editing theme files, and verify the change on a product page and on the home page afterwards.
