## Agent prompt

No change is needed: this check is informational and never fails. It records how the BigCommerce storefront is built, as listed in the evidence: a Stencil theme, a headless Next.js storefront such as Catalyst, or another headless front end. Use it to know where a fix from another check belongs. In a Stencil theme, markup, structured data and meta tags live in the theme's Handlebars templates (templates/layout, templates/pages, templates/components), edited with the Stencil CLI or Page Builder, ideally on a copy of the theme. In Catalyst or another headless storefront, the front-end application renders every page, so fixes go into its code, not into a Stencil theme. Only if the recorded storefront is wrong, check that a Stencil theme still calls stencilBootstrap on the home page, and rescan.
