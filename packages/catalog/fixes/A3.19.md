## Agent prompt

No change is needed: this check is informational and never fails. It records how the Salesforce B2C Commerce storefront is built, as listed in the evidence: a storefront B2C Commerce renders on its own servers (the Storefront Reference Architecture, SFRA, or the older SiteGenesis), or the Composable Storefront built with PWA Kit on Managed Runtime. Use it to know where a fix from another check belongs. In SFRA or SiteGenesis, markup, structured data and meta tags live in the ISML templates of the site's custom cartridges, which override the base cartridge; never edit app_storefront_base itself. In the Composable Storefront, the React application renders every page, so fixes go into the PWA Kit project and are deployed as a new bundle to Managed Runtime. Only if the recorded storefront is wrong, check which assets the home page loads (/on/demandware.static/ or /mobify/bundle/), and rescan.
