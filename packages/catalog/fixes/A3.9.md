## Summary

Send an ETag or Last-Modified header on product pages and answer conditional requests with 304 Not Modified, so crawlers can confirm a page is unchanged without downloading it.

## Snippet

```bash
curl -sI https://example.shop/product/mug/ | grep -i etag
curl -sI -H 'If-None-Match: "abc123"' https://example.shop/product/mug/ | head -1   # expect HTTP/1.1 304
```

## Agent prompt

A scan found that product pages on this site send no ETag or Last-Modified header, or ignore it and answer 200 to a conditional request. Configure the web server, application or CDN to emit a strong ETag (or an accurate Last-Modified) on HTML product pages and to answer If-None-Match and If-Modified-Since with 304 Not Modified when the page is unchanged. On nginx, keep `etag on` and make sure the application does not strip the header. On Apache, use FileETag and mod_cache. On a CDN or a cache plugin, enable conditional-request handling for HTML, not only for static assets. Build the validator from the content or the product's last update, so a price change produces a new one, and keep per-visitor fragments such as a mini cart out of the cached HTML. Verify with `curl -sI <product URL>` to read the ETag, then `curl -sI -H 'If-None-Match: <etag>' <product URL>` and expect HTTP 304.
