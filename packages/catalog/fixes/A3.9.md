## Summary

Send an ETag or Last-Modified header on product pages and answer conditional requests with 304 Not Modified, so crawlers can confirm a page is unchanged without downloading it.

## Snippet

```bash
curl -sI https://example.shop/product/mug/ | grep -i etag
curl -sI -H 'If-None-Match: "abc123"' https://example.shop/product/mug/ | head -1   # expect HTTP/1.1 304
```

## Agent prompt

Configure the web server, application or CDN to emit a strong ETag (or an accurate Last-Modified) on HTML product pages and to honour If-None-Match and If-Modified-Since with 304 Not Modified when the page is unchanged. On nginx, ensure etag on and that the application does not strip it; on Apache, FileETag and mod_cache; on a CDN or WordPress cache plugin, enable conditional-request handling for HTML, not only for static assets. Verify with curl -sI to read the ETag, then curl -sI -H 'If-None-Match: <etag>' and expect HTTP 304.
