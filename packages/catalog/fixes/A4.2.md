## Summary

Publish an API catalog linkset at /.well-known/api-catalog listing the store's public APIs.

## Snippet

```json
{
  "linkset": [
    {
      "anchor": "https://example.com/",
      "service-desc": [
        { "href": "https://example.com/api/openapi.json", "type": "application/json" }
      ]
    }
  ]
}
```

## Agent prompt

Serve /.well-known/api-catalog on this site as an RFC 9727 linkset (application/linkset+json) that lists the store's public product API and any feed or checkout endpoints.

## On WooCommerce

List the Store API at /wp-json/wc/store/v1 under service-desc.
