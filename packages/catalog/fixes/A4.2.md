## Summary

Publish an API catalog linkset at /.well-known/api-catalog listing the store's public APIs.

## Snippet

```json
{
  "linkset": [
    {
      "anchor": "https://example.shop/",
      "service-desc": [
        { "href": "https://example.shop/wp-json/wc/store/v1", "type": "application/json" }
      ]
    }
  ]
}
```

## Agent prompt

Serve /.well-known/api-catalog on this site as an RFC 9727 linkset (application/linkset+json) that lists the public Store API and any feed or checkout endpoints.
