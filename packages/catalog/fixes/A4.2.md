## Summary

Publish an RFC 9727 API catalog at `/.well-known/api-catalog`: a JSON linkset, served as `application/linkset+json`, that lists the store's public APIs.

## Snippet

```json
{
  "linkset": [
    {
      "anchor": "https://example.com/",
      "service-desc": [
        { "href": "https://example.com/api/openapi.json", "type": "application/json" }
      ]
    }
  ]
}
```

## Agent prompt

A scan found that `/.well-known/api-catalog` on this site answers an error status, an HTML page, a body without a `linkset` array, or a linkset that lists no links. Serve that exact path, without a redirect, as an RFC 9727 linkset with `Content-Type: application/linkset+json`. List the store's public APIs that outside clients may call without special arrangement (the public product or storefront API, a product feed) as `item` links, and link any OpenAPI description with `service-desc` and human documentation with `service-doc`. Do not list admin or authenticated APIs. Because the file has no extension, configure the web server to send the content type. Verify with `curl -si https://<host>/.well-known/api-catalog`: status 200, the linkset content type, and JSON with a non-empty `linkset` array.

## On WooCommerce

List the public Store API at `/wp-json/wc/store/v1` as an `item` link. Leave out the admin routes under `/wp-json/wc/v3`.
