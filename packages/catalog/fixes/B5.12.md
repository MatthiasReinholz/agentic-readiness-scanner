## Summary

Informational, nothing to fix. This check records whether the cart and checkout pages use WooCommerce's Cart and Checkout blocks or the classic shortcodes. Agents that buy for a shopper work through the Store API (B5.7), which either kind of page leaves in place.

## Agent prompt

No change is needed: this check is informational and never fails. It records whether the store's cart and checkout pages use WooCommerce's Cart and Checkout blocks or the classic [woocommerce_cart] and [woocommerce_checkout] shortcodes (or a page builder or checkout plugin), as listed in the evidence. If the store owner wants to switch, follow WooCommerce's guide "Customizing the Cart and Checkout pages": to move to the blocks, delete the Shortcode block on each page and insert the Cart or Checkout block; to go back, transform each block to "Classic Shortcode". Switch both pages together, because they work as a pair. Before switching to the blocks, confirm that every payment gateway and checkout extension the store uses supports them, since an incompatible gateway may not appear as a payment option. Test a full order on a staging copy, then rescan. Do not change the Store API or guest checkout settings while doing this.
