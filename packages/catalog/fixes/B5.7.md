## Summary

Keep the WooCommerce Store API cart endpoint open to anonymous clients and enable guest checkout in the WooCommerce settings.

## Agent prompt

On this WooCommerce store, the Store API cart does not answer anonymous clients, or the checkout page requires a login. Make sure GET `/wp-json/wc/store/v1/cart` responds 200 with a JSON cart (items and totals) for a client without cookies: allow the wc/store namespace in any plugin that restricts the REST API, keep pretty permalinks on, and exclude `/wp-json/wc/store/` from page and CDN caching. Enable guest checkout under WooCommerce > Settings > Accounts & Privacy. Verify with `curl -si .../wp-json/wc/store/v1/cart` and by opening the checkout page in a private window.
