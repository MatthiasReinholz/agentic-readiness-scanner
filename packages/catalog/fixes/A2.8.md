## Summary

Untick Settings > Reading > Search engine visibility ("Discourage search engines from indexing this site") once the site is live, and remove any noindex an SEO plugin sets on the home page. WordPress then drops the noindex tag and turns its sitemap back on.

## Agent prompt

This WordPress site's home page asks search engines not to index it. In the WordPress admin, open Settings > Reading and untick "Discourage search engines from indexing this site", then save. If an SEO plugin (Yoast SEO, Rank Math, All in One SEO or similar) also sets noindex for the home page or the whole site, switch that off in the plugin's settings too. Check wp-config.php and the theme for code that filters wp_robots or prints a robots meta tag. Afterwards, confirm that the home page HTML no longer contains a robots meta tag with noindex, that no X-Robots-Tag header with noindex is sent, and that /wp-sitemap.xml (or the SEO plugin's sitemap) answers again. Do not change robots.txt rules for other crawlers.
