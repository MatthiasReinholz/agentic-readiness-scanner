## Summary

Serve a plain-text robots.txt at the site root that returns HTTP 200 and parses under RFC 9309. Even an empty file is better than a missing file, a 5xx error or a challenge page.

## Snippet

```robots
User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml
```

## Agent prompt

The scanner could not read a valid robots.txt on this site: /robots.txt answered with a 4xx or 5xx status, gave no response, or returned an HTML page (a challenge page or a soft 404) instead of plain text. Make /robots.txt return HTTP 200 with content type text/plain and a body in robots.txt format (RFC 9309). Keep any existing rules, and add a Sitemap line with the absolute URL of the sitemap index. If a CDN, firewall or bot-protection service sits in front of the site, exempt /robots.txt from challenges and rate limits. If a catch-all route answers unknown paths, make sure it does not answer /robots.txt. Verify with `curl -sS -D - https://<domain>/robots.txt`: the status must be 200, the content type text/plain and the body must start with rules such as `User-agent`, not HTML.

## On WordPress

Use the robots_txt filter or the SEO plugin's robots.txt editor rather than a static file, so the output stays in step with the settings. A physical robots.txt in the web root overrides the virtual one.

## On Shopify

Shopify generates robots.txt. Change it only through the robots.txt.liquid theme template, never by replacing it.

## On Magento

Adobe Commerce serves robots.txt from the admin. Edit it under Content > Design > Configuration > Search Engine Robots, where "Reset to Default" restores the standard rules.

## On PrestaShop

Generate the file under Shop Parameters > Traffic & SEO with "Generate robots.txt". It replaces the existing file, so add custom rules again afterwards.

## On Webflow

Write the rules under Site settings > SEO > Indexing and publish. Webflow adds the sitemap line by default.

## On Wix

Wix generates robots.txt. Change it only in the Robots.txt Editor of the SEO tools.

## On BigCommerce

BigCommerce manages robots.txt in the control panel and keeps a separate rule set for AI crawlers that merchants cannot edit.
