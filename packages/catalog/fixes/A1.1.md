## Summary

Serve a plain-text robots.txt at the site root that returns HTTP 200 and parses under RFC 9309. Even an empty file is better than a 5xx or a challenge page.

## Snippet

```robots
User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml
```

## Agent prompt

Make /robots.txt on this site return HTTP 200 with content type text/plain and a body that parses under RFC 9309. Keep existing rules; add a Sitemap line pointing at the sitemap index.

## On WordPress

Use the robots_txt filter rather than a static file so the output stays in sync with settings.

## On Shopify

Shopify generates robots.txt; change it only through the robots.txt.liquid theme template, never by replacing it.

## On Magento

Adobe Commerce serves robots.txt from the admin: edit it under Content > Design > Configuration > Search Engine Robots, where "Reset to Default" restores the standard rules.

## On PrestaShop

Generate the file under Shop Parameters > Traffic & SEO with "Generate robots.txt"; it replaces the existing file, so add custom rules again afterwards.

## On Webflow

Write the rules under Site settings > SEO > Indexing and publish; Webflow adds the sitemap line by default.

## On Wix

Wix generates robots.txt; change it only in the Robots.txt Editor of the SEO tools.

## On BigCommerce

BigCommerce manages robots.txt in the control panel and keeps a separate rule set for AI crawlers that merchants cannot edit.
