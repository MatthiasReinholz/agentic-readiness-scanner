## Summary

Give every product page one absolute, self-referencing rel=canonical over HTTPS, keep the HTML and Link-header canonicals in agreement, and, when the store runs in several languages, absolute hreflang alternates with an x-default on every page.

## Snippet

```html
<link rel="canonical" href="https://example.com/product/stoneware-mug/" />
<link rel="alternate" hreflang="en" href="https://example.com/product/stoneware-mug/" />
<link rel="alternate" hreflang="de" href="https://example.com/de/produkt/steinzeug-becher/" />
<link rel="alternate" hreflang="x-default" href="https://example.com/product/stoneware-mug/" />
```

## Agent prompt

Audit rel=canonical on the product pages of this store. Each page must carry exactly one canonical, as an absolute https URL that is the page's own final URL (the address that answers 200, with the same trailing slash and no tracking parameters). Remove duplicate or conflicting canonicals, including a Link response header that disagrees with the HTML. If a product page's canonical points to another URL on purpose (a variant pointing to its parent, a parameterised URL pointing to the clean one), make the sitemap and internal links name that canonical URL instead. When the store serves several languages, add hreflang alternates with absolute URLs, list every language plus x-default, and make the set identical on every alternate page. Verify with curl on two product pages.
