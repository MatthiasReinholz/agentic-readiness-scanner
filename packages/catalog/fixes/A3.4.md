## Summary

Add a rel=canonical link on every product page and, when the store runs in several languages, hreflang alternates for each.

## Snippet

```html
<link rel="canonical" href="https://example.com/product/stoneware-mug/" />
<link rel="alternate" hreflang="de" href="https://example.com/de/produkt/steinzeug-becher/" />
```

## Agent prompt

Ensure every product page on this site emits a single rel=canonical link to its own URL on the primary origin, and when multilingual, hreflang alternates for each language including x-default. Most SEO plugins do this; enable it rather than hand-coding.
