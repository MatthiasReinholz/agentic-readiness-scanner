## Summary

If the site exposes an A2A agent, publish its agent card at /.well-known/agent-card.json with the eight fields A2A 1.0 requires: name, description, supportedInterfaces, version, capabilities, defaultInputModes, defaultOutputModes and skills.

## Agent prompt

If this site operates an A2A agent, publish /.well-known/agent-card.json as JSON with name, description, supportedInterfaces (each with a binding and protocolVersion), version, capabilities, defaultInputModes, defaultOutputModes and skills, and remove the pre-0.3 /.well-known/agent.json copy. Do not publish a card for an agent that does not exist.
