## Summary

If your store honours Global Privacy Control (GPC), say so: publish `/.well-known/gpc.json` with `"gpc": true` and describe how you treat the signal in your privacy notice. Only declare it once the signal really turns off the sale and sharing of data, and have a lawyer review the notice.

## Snippet

```json
{
  "gpc": true,
  "lastUpdate": "2026-11-03"
}
```

## Agent prompt

Declare Global Privacy Control support for this store, but only after confirming the store honours it. First check that a browser request with the `Sec-GPC: 1` header, or a page where `navigator.globalPrivacyControl` is true, results in the visitor being opted out of the sale and sharing of personal information (advertising pixels and data sharing switched off, consent banner defaulting to opted out). If it does not, implement that first through the consent management platform's GPC setting or the platform's own customer privacy API, and report what you changed. Then serve a file at `https://<store>/.well-known/gpc.json` with `Content-Type: application/json` and the body `{"gpc": true, "lastUpdate": "YYYY-MM-DD"}`, using today's date. Add a short paragraph to the privacy notice saying the store treats GPC as a valid request to opt out of sale and sharing, and how a visitor can see that it was applied. Leave a note that a lawyer must review the privacy notice wording.

## On WordPress

Place the file in the web root's `.well-known` directory or serve it from a small route.

## On Shopify

The root cannot hold arbitrary files: use a URL redirect or an app that serves well-known files, and check that the final response is JSON.
