## Summary

Fix the basics in your templates: declare the page language, give every page a title, add alt text to content images, label every form field, give icon-only links and buttons an accessible name, and stop blocking zoom in the viewport tag. Then test with real users and tools, because these basics are only a small part of accessibility.

## Snippet

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <!-- Allow zoom: no user-scalable=no, no maximum-scale below 2 -->
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Stoneware Mug, 350 ml | Example Ceramics</title>
  </head>
  <body>
    <!-- Content image: describe it. Decorative image: empty alt. -->
    <img src="/images/mug-1200.jpg" alt="Grey stoneware mug with a curved handle, 350 ml" />
    <img src="/images/divider.svg" alt="" />

    <!-- Form control with a visible label -->
    <label for="qty">Quantity</label>
    <input id="qty" name="quantity" type="number" min="1" value="1" />

    <!-- Search field without a visible label: give it an accessible name -->
    <input type="search" name="q" aria-label="Search products" />

    <!-- Icon-only button and link: name them -->
    <button type="button" aria-label="Add to wishlist">
      <svg aria-hidden="true" focusable="false"><use href="#icon-heart" /></svg>
    </button>
    <a href="/cart" aria-label="Cart, 2 items">
      <svg aria-hidden="true" focusable="false"><use href="#icon-cart" /></svg>
    </a>
  </body>
</html>
```

## Agent prompt

Fix the static accessibility basics in this store's templates, for the home page and product pages first. 1) Make sure the root html element has a `lang` attribute matching the page language (and the right value per locale on multilingual sites). 2) Make sure every page has a non-empty, descriptive `title`. 3) Give every content image a meaningful `alt` text taken from the product or media data. Give purely decorative images `alt=""`. Do not invent product facts. Where alt text is missing in the data, fall back to the product name and flag the images for the owner. 4) Give every form control (inputs, selects, textareas, including search, newsletter, quantity and variant pickers) a `label` element or an `aria-label`/`aria-labelledby`. 5) Give every link and button an accessible name: visible text, or `aria-label` for icon-only controls such as cart, search, wishlist, menu and social icons. Mark the icons `aria-hidden="true"`. 6) In the meta viewport tag remove `user-scalable=no` and any `maximum-scale` below 2. Prefer native HTML elements over ARIA where possible. Run an automated checker (axe, Lighthouse or WAVE) before and after, report what changed, and list what still needs manual testing: contrast, keyboard use, focus order and screen reader checks. Do not install an accessibility overlay.
