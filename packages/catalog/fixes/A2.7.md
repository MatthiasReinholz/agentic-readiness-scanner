## Summary

Allow crawlers to fetch the site's own JavaScript and CSS: remove robots.txt Disallow rules that cover script and stylesheet paths, or add Allow rules for them.

## Snippet

```text
User-agent: *
Allow: /wp-includes/js/
Allow: /wp-content/plugins/*.css
Allow: /wp-content/plugins/*.js
Disallow: /wp-admin/
```

## Agent prompt

Open robots.txt and find the Disallow rules that match the site's script or stylesheet URLs (typical culprits: Disallow: /wp-includes/, /wp-content/plugins/, /assets/, /static/, /*.js$, /*.css$). Either delete those rules or add explicit Allow rules for the asset paths (for example Allow: /wp-includes/js/, Allow: /wp-content/plugins/*.css) above them. Googlebot, Bingbot and Applebot need these files to render the page. Verify by evaluating one script URL and one stylesheet URL from a product page against the new robots.txt for Googlebot.
