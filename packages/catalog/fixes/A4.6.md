## Summary

Informational. If you want browser agents to use the site's forms as tools, declare them with WebMCP: toolname and tooldescription on the form (both are required) and toolparamdescription on its fields, or document.modelContext.registerTool in script. Do not turn the API off with Permissions-Policy: tools=() on pages that declare tools. The API is an origin trial; nothing is lost by waiting.

## Agent prompt

Only if the owner wants to experiment with WebMCP: annotate the key forms of this site (search, add to cart, contact) with a toolname and a tooldescription (the browser registers no tool without both) and per-field toolparamdescription attributes, as described in Chrome's declarative WebMCP documentation, or register the same actions with document.modelContext.registerTool behind a feature check. Make sure no Permissions-Policy header on those pages contains tools=(). Test them with the WebMCP flag in Chrome or the site tools menu of the ChatGPT desktop browser. Leave production behaviour unchanged for browsers without the API.
