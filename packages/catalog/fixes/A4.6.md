## Summary

Informational. If you want browser agents to operate the site's forms as tools, declare them with WebMCP (toolname, tooldescription and toolparamdescription on the form, or document.modelContext.registerTool). The API is an origin trial; nothing is lost by waiting.

## Agent prompt

Only if the owner wants to experiment with WebMCP: annotate the key forms of this site (search, add to cart, contact) with toolname, tooldescription and per-field toolparamdescription attributes as described in Chrome's declarative WebMCP documentation, or register the same actions with document.modelContext.registerTool, and test them with the WebMCP flag in Chrome. Leave production behaviour unchanged for browsers without the API.
