## Summary

Load advertising and analytics tags only after the visitor agrees: block them in the HTML until consent (or set Google Consent Mode defaults to denied), and stop the server from setting tracking cookies on the first response. Have a lawyer review the consent banner and cookie notice.

## Snippet

```html
<!-- Defaults first, before any Google tag loads -->
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag() {
    dataLayer.push(arguments);
  }
  gtag('consent', 'default', {
    ad_storage: 'denied',
    ad_user_data: 'denied',
    ad_personalization: 'denied',
    analytics_storage: 'denied',
  });
</script>
<!-- Other trackers stay inert until the consent tool enables them -->
<script
  type="text/plain"
  data-category="marketing"
  src="https://connect.facebook.net/en_US/fbevents.js"
></script>
```

## Agent prompt

Make this store load no advertising or analytics trackers before the visitor consents. First list every tracker in the server-rendered HTML of the home page (Google tag, Google Tag Manager, Meta pixel, TikTok, LinkedIn, Hotjar, Pinterest and similar) and every `Set-Cookie` header on the first response. For each tracker tag, either let the consent management platform block it (change the tag to `type="text/plain"` with the platform's category attribute, such as `data-cookieconsent` or `data-category`, so the platform enables it after consent) or, for Google tags, add a Consent Mode default with `ad_storage`, `ad_user_data`, `ad_personalization` and `analytics_storage` set to `denied` before the tag loads. Remove any server-side code, plugin or proxy that sets advertising cookies such as `_fbp` or `_gcl_au`, or analytics cookies such as `_ga`, on the first response. On WordPress/WooCommerce, prefer the consent plugin's script-blocking and the analytics plugin's consent integration over editing theme files; on Shopify, use the customer privacy settings and apps that read the Customer Privacy API. Verify with `curl -sI` and by viewing the page source without accepting the banner. Do not change the banner text or cookie notice wording; leave a note that a lawyer must review them.
