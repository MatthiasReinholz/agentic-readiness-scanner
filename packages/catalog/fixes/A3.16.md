## Summary

Informational, nothing to fix. This check records whether an Online Store theme or a headless storefront such as Hydrogen serves the Shopify store, and which theme it is. Neither is better for agents by itself; what counts is the HTML each serves, which the other checks score.

## Agent prompt

No change is needed: this check is informational and never fails. It records how the Shopify store's storefront is built, as listed in the evidence: an Online Store theme (its name and version, and its Theme Store id when Shopify sets one), a Hydrogen storefront, or another headless front end. Use it to know where a fix from another check belongs. In an Online Store theme, markup, structured data and meta tags live in the theme's Liquid files (layout/theme.liquid, sections and snippets), edited under Online Store > Themes > Edit code, and a theme from the Theme Store is best changed through its settings or a duplicated copy so updates stay possible. In a Hydrogen or other headless storefront, the front-end application renders every page, so fixes go into its code, not into the Shopify theme. Only if the recorded storefront is wrong, check that the home page still prints content_for_header (which writes the Shopify.theme object) or, for Hydrogen, sends its powered-by header, and rescan.
