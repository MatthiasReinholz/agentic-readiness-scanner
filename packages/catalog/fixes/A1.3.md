## Summary

Include every published product URL in the sitemap, ideally in a dedicated product sitemap referenced from the sitemap index, so an agent can enumerate the catalog without crawling.

## Agent prompt

Check how this site generates its sitemap and ensure every published product URL appears in it, preferably in a product sitemap that the sitemap index references. If an SEO plugin or the platform manages sitemaps, enable product URLs there instead of writing a static file, and verify the index references the product sitemap. On WordPress/WooCommerce: make sure the product post type is not excluded from the sitemap by the SEO plugin or the core sitemap settings.
