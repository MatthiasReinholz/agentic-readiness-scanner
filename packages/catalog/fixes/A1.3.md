## Summary

Include every published product URL in the sitemap, ideally in a dedicated product sitemap listed in the sitemap index, so an agent can list the catalog without crawling.

## Agent prompt

The scanner read this site's sitemap but found no product URLs in it: no child sitemap named as a product sitemap (such as product-sitemap.xml, wp-sitemap-posts-product-1.xml or sitemap_products_1.xml) could be read, and no entry has a product path segment such as /product/ or /products/. Find out how the site generates its sitemap and make sure every published product URL appears in it, preferably in a product sitemap with "product" in its file name that the sitemap index lists. If an SEO plugin or the platform manages sitemaps, enable products there instead of writing a static file. Keep the file uncompressed and under 2 MB, or split it. Verify by fetching the sitemap index, opening the product sitemap it lists and checking that its entry count is close to the number of published products.

## On WordPress

Make sure the SEO plugin or the core sitemap settings do not exclude the product post type.

## On Shopify

Shopify lists a product in its generated sitemap only when it is published to the Online Store channel. Check the product's sales channels.
