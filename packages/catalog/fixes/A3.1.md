## Summary

Answer requests with Accept: text/markdown on product and policy pages with a Markdown rendering (title, price, stock, attributes, identifiers, description, policy links), send Vary: Accept, or publish a .md twin linked with rel=alternate.

## Snippet

```http
Accept: text/markdown

HTTP/1.1 200 OK
Content-Type: text/markdown; charset=utf-8
Vary: Accept
```

## Agent prompt

Implement content negotiation on this site so that a request for a product or policy page with `Accept: text/markdown` receives a Markdown rendering served as `text/markdown; charset=utf-8` with a `Vary: Accept` header: title, price, availability, attributes, SKU and GTIN, description and links to the policies. If negotiation is impractical, serve the same Markdown at the page URL with `.md` appended and link it with `<link rel="alternate" type="text/markdown">`. On WordPress/WooCommerce, prefer the platform's own hooks and settings over editing theme files, and verify the change on a product page and on the home page afterwards.
