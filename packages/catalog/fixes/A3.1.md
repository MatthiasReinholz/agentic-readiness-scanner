## Summary

Answer requests with Accept: text/markdown on product and policy pages with a Markdown rendering of the product: title, price, stock, attributes, identifiers, description and policy links.

[Shipping](https://example.com/shipping/) · [Returns](https://example.com/returns/)

## Agent prompt

Add content negotiation to product and policy pages on this site: when the Accept header prefers text/markdown, respond with Content-Type: text/markdown and a Markdown document built from the product data (title, price, stock status, attributes, SKU, GTIN, brand, description, policy links). Add Vary: Accept and keep the HTML response unchanged for other clients. Build the Markdown from the same product object the HTML template uses so the two never drift. On WordPress/WooCommerce: hook template_redirect, read the product through wc_get_product() and send the Markdown before the theme renders.
