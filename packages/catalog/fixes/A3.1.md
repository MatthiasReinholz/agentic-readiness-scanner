## Agent prompt

A scan found that the product pages of this site offer no usable Markdown copy: no Markdown at all, Markdown without a `Vary: Accept` header, or HTML labelled `text/markdown`. Make a request for a product page with `Accept: text/markdown` return a Markdown rendering generated from the product data (not by stripping tags from the HTML): an H1 with the product name, then price with currency, availability, SKU and GTIN, attributes, description and links to the policies. Serve it as `text/markdown; charset=utf-8` with `Vary: Accept`, and make sure the page cache varies on `Accept` or bypasses these requests. If negotiation is impractical, serve the same Markdown at the page URL with `.md` appended and link it from the HTML head with `<link rel="alternate" type="text/markdown" href="...">`. Verify with `curl -sS -D - -H 'Accept: text/markdown' <product URL>`: the response must be `text/markdown`, carry `Vary: Accept`, start with a heading or front matter and name the product.
