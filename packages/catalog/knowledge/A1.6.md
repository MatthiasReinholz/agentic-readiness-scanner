## In short

llms.txt is an optional Markdown file at the root of a site that summarises it for AI tools and links to its key pages. If your store publishes one, its most useful job is to send an agent straight to your catalog as data. A link to a product feed (a file listing every product), a store API (an interface that returns products as JSON), a product sitemap or a commerce profile does that in one hop. This check passes when at least one link in llms.txt points at the catalog as data, and is skipped when there is no llms.txt.

This check is informational: it is reported but never scored. No major assistant documents reading llms.txt, so which links the file lists is a hint, not a readiness finding.

## What this check looks at

The check reads the links in your `/llms.txt`, the same file the [llms.txt check](/knowledge-base/llms-txt-valid) validates. It looks for links that lead to product data rather than to prose pages such as "About us" or a blog.

A link counts as a catalog link when its URL or its link text matches one of these patterns:

| Pattern                      | Examples                                             |
| ---------------------------- | ---------------------------------------------------- |
| A feed                       | `/feed/products.xml`, a link labelled "Product feed" |
| A WooCommerce Store API path | `/wp-json/wc/store/v1/products`                      |
| A products file              | `/products.json`, `/products.xml`, `/products.csv`   |
| A product sitemap            | `/product-sitemap.xml`, `/sitemap_products_1.xml`    |
| The shop or products index   | a URL ending in `/shop/`, `/products` or `/product/` |
| The word catalog             | a URL or link text containing "catalog"              |
| A UCP endpoint               | `/.well-known/ucp` or `/api/ucp/mcp`                 |

The last row covers the Universal Commerce Protocol (UCP). Shopify's generated llms.txt links the store's UCP business profile at `/.well-known/ucp` and its UCP endpoint for the Model Context Protocol (MCP) at `/api/ucp/mcp`. An agent that follows either reaches the catalog as data.

## Why it matters for AI agents

An agent that reads llms.txt has been pointed at your site on purpose, usually by a user or a developer. It wants to answer a question about your products quickly. Links to policy pages and blog posts send it back to reading HTML. A link to a feed or an API gives it structured product data, with prices and availability, in a single request.

Keep expectations realistic. The llms.txt proposal has no documented reader among the major assistants, and Google states that Search does not use it. This check never affects a level, and a store without llms.txt is not marked down.

## How the scanner decides

- **Skip:** there is no llms.txt (the file answers 404 or 410). The check does not apply.
- **Skip:** llms.txt exists but failed the [llms.txt check](/knowledge-base/llms-txt-valid), for example because it is an HTML page. Fix that first.
- **Pass:** at least one link matches a pattern in the table above. The report names the catalog links it found and notes when one of them is a UCP profile or UCP MCP endpoint.
- **Fail:** llms.txt is valid but none of its links matches. A file that has a heading and no links at all also fails here.

Only Markdown links in the form `[text](url)` count. A bare URL on its own line is not parsed as a link.

## How to fix it

Add an H2 section named "Catalog" to llms.txt, with one link per machine-readable source you already serve. Add a short note after each link that says what it returns. Do not link sources that do not exist or require a login.

### WordPress and WooCommerce

- WooCommerce exposes a public Store API. Link its product endpoint, `https://your-store/wp-json/wc/store/v1/products`, and describe it as JSON with live price and stock.
- Link the product sitemap your site already serves: `wp-sitemap-posts-product-1.xml` with core sitemaps, or `product-sitemap.xml` with Yoast SEO or Rank Math.
- If a marketing plugin publishes a product feed for Google Merchant Center at a public URL, link that too.
- If a plugin generates llms.txt for you, check whether it can include these links before you replace it with a static file.

### Shopify

- If Shopify generates your llms.txt, check whether it already links `/.well-known/ucp` or `/api/ucp/mcp`. If it does, this check passes without changes.
- Otherwise, link `https://your-store/products.json`, which lists published products as JSON, and the product sitemap `sitemap_products_1.xml` from your `/sitemap.xml` index.

### Any other stack

- Link your public product feed, your product API documentation or endpoint, and your product sitemap.
- If you publish an API catalog under `/.well-known/api-catalog`, link it as well. Agents that understand RFC 9727 can discover your APIs from it.
- Keep the URLs absolute and stable. A feed URL with a session token or a dated filename breaks the link the next day.

## Verify it yourself

Print every link in your llms.txt and look for catalog sources:

```bash
curl -s https://example.com/llms.txt | grep -o '\[[^]]*\]([^)]*)'
```

Then open each catalog link with `curl -sI` to confirm it answers HTTP 200 without a login.

## Common mistakes

- **Linking only prose pages.** About, blog and FAQ links help a human reader. They do not lead an agent to product data.
- **Linking a private feed.** A Merchant Center feed URL that needs credentials, or an admin API, is useless to an agent.
- **Bare URLs instead of Markdown links.** The proposal uses Markdown link lists. A plain URL on a line is not read as a link.
- **Linking a feed that is out of date.** An agent that reads stale prices from a linked feed is worse off than one that reads your product page. See [product feed freshness](/knowledge-base/product-feed-freshness).

## FAQ

### What links should a store's llms.txt include?

At minimum a Catalog section with the product feed, the store API and the product sitemap, followed by a Policies section with shipping, returns and privacy. Link only public, working URLs.

### Is products.json a good link for a Shopify store?

Yes. Shopify's `/products.json` returns published products as JSON, and the scanner counts it as a catalog link. A UCP profile link, if your store has one, counts as well.

### My store has no llms.txt. Does this check fail?

No. It is skipped as not applicable. Neither llms.txt nor its catalog links are needed for any level.

### Does the link text matter?

A little. The scanner matches both the URL and the link text, so a link labelled "Product feed" or "Catalog" counts. Clear link text also helps any reader understand what the link returns.
