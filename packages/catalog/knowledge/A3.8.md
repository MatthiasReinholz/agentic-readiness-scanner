## In short

Every page should carry a `title` element that names it and a meta description that says what it offers. The title is the one field answer engines show with every citation, and Bing ties missing titles and descriptions to whether a page can be used for grounding, that is, as a source for an AI answer. This check reads both on the home page, a listing page and the sampled product pages, and flags pages without a title, shared titles, very short titles and missing descriptions.

## What this check looks at

Two pieces of the HTML head:

- **The title element.** For example "Stoneware Mug 350 ml | Berlin Ceramics". Browsers show it in the tab. Search engines and assistants use it as the name of the page in results and citations.
- **The meta description.** A `meta` element with `name="description"`, for example "Hand-thrown stoneware mug, dishwasher safe, 350 ml." It is a short summary of the page. Google documents that it sometimes uses it for the snippet under a result.

The scanner reads them from the server-rendered HTML of three kinds of page: the home page, one sampled listing page such as a category, and each sampled product page. Pages that did not answer are recorded but not judged. Their status is the business of other checks.

## Why it matters for AI agents

When an assistant cites a source, it shows a title and a link. A page with no title leaves the assistant to invent a label or to skip the page. Bing's webmaster guidelines, which cover search, Copilot and grounding, name missing titles and short or missing descriptions as reducing a page's eligibility.

Titles also tell pages apart. If every product page is called "Shop", an index cannot distinguish them and an assistant cannot tell the buyer which one it means. A unique title that names the product and the store makes each page citable on its own.

A description gives the index a summary written by you rather than one guessed from the page text. Google may still write its own snippet, but a good description is the best input you control.

## How the scanner decides

- **Fail** when any judged page has no `title` element or an empty one.
- **Warn** when two or more judged pages share the same title. Comparison ignores case and extra whitespace.
- **Warn** when a title is shorter than ten characters. That is too short to identify a page in a citation.
- **Warn** when a page has no meta description or an empty one.
- **Pass** when every judged page has a distinct title of at least ten characters and a non-empty description.

The checks run in that order, so a store with a missing title sees the fail first. Maximum lengths are not judged, because no engine documents one. The report lists every page with its title, the title length and whether a description was found.

This check has weight 2: expected, not blocking. It gates no level.

## How to fix it

Write titles as "what this page is | store name". Write descriptions as one or two plain sentences about what the page offers. Use the platform's own fields before you touch templates.

### WordPress and WooCommerce

- WordPress builds the title from the page or product name when the theme declares `title-tag` support, which current themes do. A missing title usually means an old theme that prints its own `title` element incorrectly or not at all.
- WordPress does not output a meta description by itself. An SEO plugin such as Yoast SEO or Rank Math adds one, with a field per product and a template for products without a hand-written text.
- Set templates for product, product category and the shop page so every page gets a fallback. Then write descriptions by hand for your best sellers.
- Check that the store's home page has its own title and description in the plugin settings, not a blank site tagline.

### Shopify

- Shopify outputs the title from `page_title` in the theme's `theme.liquid`. Every product, collection and page has a "Search engine listing" section in the admin where you set the title and description.
- When the description field is empty, most themes fall back to the product description. Check that your theme renders `page_description` in the head.
- Set the home page title and description under Online Store, Preferences.

### Any other stack

- Render the `title` element and the `meta name="description"` tag on the server in every page template, not with JavaScript after load.
- Build the title from the product name and the store name. Build a fallback description from the product's short description or first sentence.
- Make sure listing pages with filters or pagination do not all share one title. Add the category name and page number.

## Verify it yourself

Fetch a product page and read the two tags:

```bash
curl -s https://example.com/product/stoneware-mug/ | grep -iE 'title>|name="description"'
```

Repeat for a category page and the home page and compare the titles. Bing Webmaster Tools' Site Scan and Google Search Console's page reports also flag missing and duplicate titles across a whole site.

## Common mistakes

- **One title for every page.** A theme that hard-codes the store name as the title gives every page the same label.
- **Descriptions added by JavaScript.** A tag injected after load is invisible to crawlers that read the raw HTML.
- **Blank SEO fields with no template.** The plugin outputs an empty `content=""` description, which counts as missing.
- **Padding titles to a length target.** No engine documents a minimum or maximum. Write a clear name, not a keyword list.
- **Two title elements.** A theme and a plugin each print one. Search engines may pick either, so keep exactly one.

## FAQ

### How long should a title tag be?

No search engine documents a fixed limit, so the scanner does not judge length beyond a minimum of ten characters. Lead with what the page is, add the store name, and stop. Results may shorten long titles on screen.

### Does Google use my meta description?

Sometimes. Google documents that it uses the meta description for the snippet when it describes the page better than text from the page itself. Bing names short or missing descriptions as reducing eligibility. Writing one costs little and gives you control over the summary.

### Why are duplicate titles only a warning?

Duplicate titles do not hide a page, but they make pages hard to tell apart in results and citations. A missing title is worse because the page then has no name at all, which is why that fails.

### Do product variants need different titles?

Only if each variant has its own URL. Variants selected on one page share that page's title. Variants with separate URLs should name the variant, for example the colour or size, so the titles are distinct.
