## In short

Shopify exposes eligible Online Store storefronts to AI agents through its Agentic storefronts channel. A store with the channel active sends a `Link` header pointing to its UCP profile and answers MCP requests at `/api/ucp/mcp`. This check looks for both. It applies only to Shopify-served storefronts, carries weight 3, blocking, and is one of the alternatives that satisfy the readable-catalog gate from Level 2 upward.

## What this check looks at

Shopify's help center describes Agentic storefronts as the way customers discover and buy a store's products in AI channels. It lists channels such as ChatGPT, Google AI Mode and Gemini, and Microsoft Copilot. The channel is active by default for eligible stores. Merchants manage it in the Shopify admin under Sales channels, in the Agentic section, where they choose the AI channels they sell on.

Two public signals show the channel at work on the storefront itself:

- **The UCP Link header.** Shopify adds `Link: </.well-known/ucp>; rel="ucp"` to storefront responses. It points to the store's Universal Commerce Protocol (UCP) business profile, which the [UCP profile check](/knowledge/ucp-business-profile) reads.
- **The storefront catalog MCP endpoint.** Shopify documents a Model Context Protocol (MCP) server at `https://{store domain}/api/ucp/mcp`. It accepts JSON-RPC 2.0 over POST and offers catalog tools such as `search_catalog`, `lookup_catalog` and `get_product`. Shopify's documentation says agents identify themselves in each request with a link to their own UCP agent profile.

Shopify also documents checkout over MCP for agents. This check does not touch checkout.

## Why it matters for AI agents

On Shopify, this channel is how the platform hands your catalog to AI agents in a structured way. An agent that reaches `/api/ucp/mcp` can search and read products without crawling pages. That is why the check is weight 3 and why the scanner accepts it as proof of a readable catalog for Level 2, next to a product sitemap, the store API, `products.json` or a public feed.

A fail almost always has a cause outside a setting. Because the channel is on by default, a missing signal means the store is not eligible or the channel was turned off.

Passing shows that the endpoint and the profile link exist. It does not mean an agent will recommend or buy your products. Product data quality, policies and the AI channel's own choices still decide that.

## How the scanner decides

The check runs only on stores detected as Shopify. A headless storefront, one that uses Shopify for its catalog but is served from another host, gets neither the profile nor the endpoint on its own domain. The scanner treats it as not applicable rather than failing it.

The scanner reads the `Link` header of the home page. It then POSTs a JSON-RPC `server/discover` request to `/api/ucp/mcp` on the store's origin. An authorization problem at that endpoint arrives as a JSON-RPC error, not as an HTTP 401, so any JSON-RPC message counts as an answer.

- **Pass:** the home page carries the `rel="ucp"` link to `/.well-known/ucp`, and `/api/ucp/mcp` answers with a JSON-RPC message. The channel is active and its catalog tools are reachable.
- **Warn:** only one of the two holds. Also a warning: the link is present, but the scanner did not call the endpoint because the store's robots.txt disallows it for the scanner's user agent.
- **Fail:** there is no `rel="ucp"` link and the endpoint does not answer.

Only a pass satisfies a level gate. A store whose result is a warning still reaches Level 2 if another catalog alternative passes, such as the [products.json check](/knowledge/shopify-products-json).

## How to fix it

Look for the cause before you look for a switch.

### Shopify

- Open Sales channels in the Shopify admin and confirm the Agentic channel is present and active. If it was turned off, turn it back on and choose the AI channels you want.
- If the channel is absent, check eligibility. A storefront password page blocks it. Remove the password once the store is live.
- Confirm that your Shopify plan includes the channel.
- If your storefront is headless, the profile and endpoint are not served on your domain, and this check does not apply.
- If your theme's `robots.txt.liquid` disallows `/api/` for all agents, consider adding `Allow: /api/ucp/` so agents that honour robots.txt can reach the catalog endpoint.
- Check that apps or a proxy in front of the store do not strip the `Link` header from responses.

## Verify it yourself

Look for the Link header on the home page:

```bash
curl -sI https://example.com/ | grep -i '^link:.*rel="ucp"'
```

Then call the catalog endpoint:

```bash
curl -s -X POST https://example.com/api/ucp/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"server/discover","params":{}}'
```

The second command should print a JSON object that starts with `{"jsonrpc":"2.0"`. An error inside that object is fine. It still shows the endpoint is live.

## Common mistakes

- **Testing while the store is password protected.** A storefront password hides the profile and the endpoint. Test after launch.
- **Looking for a setting that does not exist.** The channel is on by default. If signals are missing, check eligibility and whether someone turned the channel off.
- **Blocking `/api/` in robots.txt for every agent.** It keeps agents that honour robots.txt away from the catalog endpoint.
- **Judging a headless storefront by this check.** On a custom front end hosted elsewhere, the endpoint lives with Shopify, not on your domain.

## FAQ

### What are Shopify agentic storefronts?

A Shopify sales channel that makes a store's products available to AI channels such as ChatGPT, Google AI Mode and Gemini, and Microsoft Copilot. It is active by default for eligible stores.

### How do I turn on Shopify agentic storefronts?

In the Shopify admin, open Sales channels and the Agentic section. It is normally already active. If it is missing, check that the store is live without a password and that your plan includes it.

### What is /api/ucp/mcp on a Shopify store?

It is Shopify's storefront catalog MCP endpoint. Agents send JSON-RPC requests to it to search the catalog and read product details.

### Why does the scanner warn that it did not call /api/ucp/mcp?

The store's robots.txt disallows that path for the scanner's user agent, and the scanner honours robots.txt. It saw the profile link but could not verify the endpoint.

### Does this check apply to headless Shopify stores?

No. A headless storefront on another host does not serve the UCP profile or the MCP endpoint on its own domain, so the check is not applicable.
