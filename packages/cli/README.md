# @agentic-readiness/cli

> Not published to npm yet; consume it through the pnpm workspace of this repository. The package name is reserved for the first npm release.

Command-line scanner and stdio MCP server of the [Agentic Readiness Scanner](https://github.com/MatthiasReinholz/agentic-readiness-scanner).

```bash
npx @agentic-readiness/cli scan https://example.com --format md
```

```bash
npx @agentic-readiness/cli mcp
```

Run `agentic-readiness help` for every option. GPL-3.0-or-later.
