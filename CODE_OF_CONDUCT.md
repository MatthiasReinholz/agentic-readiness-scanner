# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep disagreements about the work rather than the person. Harassment of any kind is not tolerated.

Report unacceptable behavior to the maintainer privately through [GitHub private vulnerability reporting](https://github.com/MatthiasReinholz/agentic-readiness-scanner/security/advisories/new) (it reaches only the maintainer, whatever the form's name says) or via the contact options on <https://matthiasreinholz.com>. Reports are handled confidentially.
